MMO 喊话大师

MMO 游戏工具 · Electron · Windows

面向 MMO 玩家的世界频道自动喊话工具。支持「自定义文案池」与「自动 API 获取」双模式，自动执行「复制 → 粘贴 → 回车」闭环。可用于招人、串频道、发布活动等多种场景。

引擎Node.js + PowerShell SendKeys
界面Chromium / 原生渲染
数据本地 JSON 持久化
